# Verticrane 운영자 안내서

크레인 기울기 기록 장치를 **현장에서 쓰는 방법**입니다. 설치·개발 문서는
[README.md](../README.md)를 보세요.

한 크레인에 **BASE(하부) / MIDDLE(중간) / TOP(상부)** 세 대를 답니다.

---

## 1. 쓰는 법

1. **전원을 켭니다.**
2. **측정 지점에서 켰다면 — 아무것도 하지 마세요.** 크레인에 올라가 장비를 다는
   동안 1분을 기다렸다가, 센서가 안정되면 **스스로 기록을 시작합니다.**
3. **차량 근처라면** 브라우저로 접속해 파일을 받습니다. 주소는 **화면 맨 아래**에
   나옵니다.

   ```
   http://192.168.0.19:8080
   ```

4. 회수한 뒤 다시 켜서 접속하면 목록에서 파일을 받습니다.

> ### 기록 중에 접속하면 그 기록은 버려집니다
>
> 장비에 접속할 수 있다는 것은 그 옆에 사람이 있다는 뜻이고, 그건 차량이지
> 크레인이 아닙니다. 그 기록은 아무도 안 왔기 때문에 시작된 것이라 책상 위의
> 상자를 재고 있었을 뿐입니다. **진짜 측정 파일은 이미 목록에 있습니다.**
>
> 버린 파일도 휴지통에 남으니 정말 필요하면 SSH로 꺼낼 수 있습니다.

### 접속이 안 될 때

`pi-tilt001.local` 같은 이름으로는 안 될 수 있습니다. 통신사 DNS가 없는 도메인에
엉뚱한 주소를 돌려주면서 mDNS 응답이 묻히기 때문입니다. **IP를 쓰세요.**

고정하고 싶으면 공유기에서 MAC 기준으로 IP를 배정하거나, Windows의
`C:\Windows\System32\drivers\etc\hosts`에 `192.168.0.19 pi-tilt001` 한 줄을 넣으면 됩니다.

**WiFi가 바뀌어 아예 접속이 안 되면** 화면도 키보드도 없어 SSH도 못 들어갑니다.
그때는 **블루투스로 Wi-Fi를 다시 붙일 수 있습니다** — [bt/README.md](../bt/README.md).

## 2. 화면 보는 법

e-paper 화면은 **전원이 꺼져도 그대로 남습니다.** 장비에 붙은 명패이기도 합니다.
지금 무엇을 하는 중이냐에 따라 **다섯 가지**가 나옵니다.

### 켜지는 중 — 전원을 넣고 10초쯤

```
┌────────────────────────────────┐
│▓ pi-tilt001              TOP  ▓│   흑백이 뒤집힌 화면입니다
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│
│▓        GEOLUX                ▓│   화면이 이렇게 바뀌면
│▓       verticrane             ▓│   장비가 살아난 것입니다
└────────────────────────────────┘
```

> **전원을 넣고 약 11초 뒤**에 바뀝니다. 그 전까지는 지난번에 끄기 직전 화면이
> 그대로 남아 있어서 **켜진 장비와 꺼진 장비가 똑같아 보입니다.** 파이가 부팅하는
> 시간이라 더 줄일 수 없습니다. 화면이 뒤집히는 것이 "살아났다"는 신호입니다.

### 설치 중 — 그다음부터, 기록이 시작될 때까지

```
┌────────────────────────────────┐
│ pi-tilt001              TOP    │
├────────────────────────────────┤
│         ↑Z                     │
│     ┌────────┐                 │  Z가 위를 향하게 답니다
│     │  ⊙Y →X │                 │
│     ├────────┤                 │
│     ▨▨▨▨▨▨▨▨                  │  빗금 친 면을 구조물에 붙입니다
│       접촉면                    │
├────────────────────────────────┤
│         192.168.0.19           │
└────────────────────────────────┘
```

### 기록 시작 — 15초간

```
│▓▓▓▓▓▓▓▓ 기록 중 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓│
```

### 측정 중 — 그다음부터

```
│          0.062                 │  기울기 (%)
│          % tilt                │
│         26.3°C                 │  온도
│ REC  2:15:23   12475 smp       │
```

### 접속 중 — 브라우저로 접속하면

```
│         GEOLUX                 │
│        verticrane              │
```

브라우저가 더 잘 보여주므로 화면에는 남길 말이 없습니다.

### 화면에 대해 알아둘 것

- **일이 생길 때만 바뀝니다.** 켜짐 · 설치 안내 · 기록 시작 · 측정 시작 · 접속 —
  이때 한 번씩입니다. 측정 화면만 1분마다 숫자를 새로 씁니다. **실시간 값은
  브라우저에서 보세요.**
- 맨 아래는 **접속 주소**입니다. `NO NETWORK`가 검은 띠로 나오면 네트워크에 아직
  못 붙은 것이고, **크레인 위에서는 정상이며 기록에는 지장이 없습니다.**
- **시각은 표시하지 않습니다.** 장비는 자기 시계가 맞는지 알 방법이 없습니다.
- **값을 보여줄 뿐 판정하지 않습니다.** 기울기가 괜찮은지는 파일을 가져가는
  서버가 정합니다.

## 3. 설치할 때

**설치 위치(BASE / MIDDLE / TOP)를 반드시 지정하세요.** 설정 화면에서 고릅니다.
지정하지 않으면 파일 이름이 `UNSET_`으로 시작해서, 나중에 어느 높이의 데이터인지
알 수 없게 됩니다. 화면 오른쪽 위에도 `UNSET`이 반전으로 나옵니다.

- 빗금 친 **아랫면**을 구조물에 붙입니다.
- **Z축이 위**를 향하게 놓습니다.
- **한번 설치한 뒤에는 방향을 바꾸지 마세요.** 방향이 바뀌면 그 전후 데이터를
  같이 볼 수 없습니다.

### 전원을 켜고 기록이 시작되기까지

| 구간 | 시간 |
|---|---|
| 전원 → 화면이 바뀜 | 약 11초 |
| 설치 유예 (크레인에 오르는 시간) | 60초 |
| 접속 대기 (네트워크가 있을 때만) | 60초 + 주소 대기 |
| 안정화 판정 | 1초 남짓 |
| **합계** | **네트워크 있음 2~4분 / 없음 약 70초** |

## 4. 파일 받기

목록에서 **받기**를 누르면 됩니다.

- 받은 파일은 목록에서 사라지고 휴지통에 **7일간** 남습니다.
- **전송이 중간에 끊기면 파일은 그대로 있습니다.** 다시 받으세요.
- 시간이 이어지는 파일은 **하나로 합쳐서** 받을 수 있습니다.

### 파일 이름 읽는 법

이름은 **설치 위치 + 슬롯 번호**입니다.

```
TOP_003.dat
 │    │
 │    └── 슬롯 번호 (000~999)
 └── 설치 위치
```

번호는 `000`부터 `999`까지 세고 다시 `000`으로 돌아오며, 그 자리에 파일이 남아
있으면 **덮어씁니다.** 장비는 노트북으로 옮기기 전의 임시 보관소이지 저장소가
아닙니다 — 받아가신 파일은 목록에서 사라지므로 평소에는 부딪칠 일이 없습니다.

**이름에 시각이 없습니다.** 언제 기록한 것인지는 **목록의 시각 열**을 보세요.

| 표시 | 뜻 |
|---|---|
| `UNSET_`로 시작 | 설치 위치를 지정하지 않았습니다 |
| `· 전원 차단 복구` | 전원이 갑자기 끊겨 마지막 1초쯤이 잘렸습니다. 나머지는 온전합니다 |

## 5. 문제가 생기면

### 기록이 시작되지 않습니다

웹 상태 화면의 **안정화 판정 표**를 보세요. 어느 지표가 기준을 넘었는지 나옵니다.
장비가 흔들리거나 제대로 안착되지 않은 경우가 대부분입니다.

접속해 있는 동안에는 자동 기록이 시작되지 않는다는 점도 확인하세요 — 브라우저를
닫고 전원을 다시 넣으면 됩니다.

### 파일 이름이 `UNSET_`으로 시작합니다

설정 화면에서 설치 위치를 지정하세요. **이미 기록된 파일의 이름은 바뀌지 않습니다** —
어느 높이인지 기억나는 동안 따로 적어 두세요.

### 시각이 이상합니다

네트워크가 없는 곳에서 켜면 시계가 **전원이 꺼져 있던 시간만큼** 뒤처집니다.
장비는 그것을 알 방법이 없어 고치지 않습니다.

- **데이터는 온전합니다.**
- **파일 안의 상대 시간(기록 시작 후 몇 초)은 어느 경우에도 정확합니다.**
- 파일들의 **순서도 맞습니다.**

절대 시각이 중요하면 **차량 WiFi가 닿는 곳에서 한 번 켠 뒤** 측정 지점으로
옮기세요.

### 화면이 안 바뀝니다

전원을 넣고 11초를 기다려 보세요. 그래도 그대로면 recorder가 뜨지 않은 것입니다.

### 한글이 네모로 나옵니다

폰트가 빠진 것입니다. 개발자에게 `sudo apt install -y fonts-nanum`을 요청하세요.

### 그 밖에

개발자용 문제 해결은 [README.md](../README.md#문제-해결)에 있습니다.
